# 🎬 Andrew Producciones

Sitio web oficial de **Andrew Producciones** — producción audiovisual profesional para bodas, seminarios y eventos.

## 🌐 Demo en vivo

👉 [Ver sitio publicado](https://andresrocha20.github.io/AR-visual-events/)

## 📋 Descripción

Página web responsiva que muestra el portafolio de fotografía y video de Andrew Producciones. Incluye:

- Presentación del negocio (hero).
- Galería de eventos.
- Información de contacto.
- Diseño adaptable a móvil, tablet y escritorio.

## 🛠️ Tecnologías usadas

- **HTML5** — estructura semántica.
- **CSS3** — diseño responsivo con Flexbox y Grid.
- **Git + GitHub** — control de versiones.
- **GitHub Pages** — hosting gratuito.
